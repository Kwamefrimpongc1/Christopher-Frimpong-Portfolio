Project

Server Monitor

A Python tool that watches CPU, memory, disk and server availability, sends alerts when something crosses a limit or goes down, keeps a history database and shows it all on a live dashboard.

View the code on GitHub ↗

What it does

  1. Reads CPU, memory and disk usage with psutil on a set interval.
  2. Checks that servers are reachable by ping, TCP port (SSH, databases) or HTTP request (websites and APIs).
  3. Raises an alert when a value crosses its limit or a server goes down, and sends a resolved message when it recovers.
  4. Delivers alerts to the console, a log file, email over SMTP, and Slack or Discord webhooks, with a cooldown so the same alert isn't repeated.
  5. Saves every reading, status check and alert to a SQLite database, and cleans up old data automatically.

The dashboard

A Flask web server exposes the data through a small API, and the dashboard polls it every 5 seconds. It shows current usage with alert limits, a history chart from 15 minutes to 7 days with hover details, uptime for each server and recent alerts. The chart is hand-drawn SVG with no chart library, and the page supports light and dark mode.

How it runs

python dashboard.py        # monitor + web dashboard on port 5050
python monitor.py          # monitor only, no web page
python monitor.py --once   # one round of checks, for testing or cron

Thresholds, the servers to check and alert channels all live in one config.yaml file, with real passwords kept in a git-ignored local copy. On Linux it runs as a systemd service that starts on boot and restarts itself if it stops.
