Project

Azure user automation lab

Creating and managing cloud users in Microsoft Entra ID, and scripting the routine parts with PowerShell.

The goal

Practice the identity work IT support, cloud administrators and security teams handle every day: creating accounts, organizing them into groups and keeping access tidy as people join and change roles.

What I did

  1. Created user accounts in Microsoft Entra ID through the Azure portal.
  2. Built groups and assigned users to them by role.
  3. Used PowerShell to automate user creation and group assignment.
  4. Documented the process in this repository.

What I learned

How cloud identity differs from on-premises Active Directory, and how administrators create, organize and manage users in Azure at scale.

Screenshots and the PowerShell script for this lab are on the way.
