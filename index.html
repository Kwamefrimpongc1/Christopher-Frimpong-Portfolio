About

I'm a data center IBX engineer at Equinix in Ashburn, Virginia, with a couple of years of hands-on work in cloud and infrastructure. I hold the CCNA, Security+ and Network+, along with AWS and Azure cloud certifications.

Before Equinix I served in the U.S. Army, supporting communications and operational systems for more than fifty soldiers. That's where I learned to troubleshoot under pressure, follow procedure to the letter and keep critical systems up.

Outside of work I build labs and tools to go deeper: Active Directory in Azure, PowerShell automation, a Python server monitor with live alerts and a browser-based file compressor. I document each one so you can see exactly how it works.
